# AtScale Semantic Layer Tools
The AtScale Semantic Layer platform creates a logical, business-friendly view of your data. This repository contains several tools and examples of how to interact programmatically with it. AtScale's semantic layer platform leverages the [Semantic Modeling Language (SML)](https://github.com/semanticdatalayer/SML). This repository contains additional example models and tools for managing semantic models, as well as conversion tools for importing and exporting SML modeling to and from various tools.

2. [Running a query using SOAP and MDX/DAX](atscale-mdx-demo)
